BLISS BY YAS — LANDING PAGE

Files:
- index.html: page content
- style.css: responsive design

HOW TO UPLOAD:
1. Download and unzip bliss_by_yas_landing_page.zip.
2. Open your hosting control panel (for example, cPanel) and open File Manager.
3. Open the website's document root, commonly public_html.
4. Upload index.html and style.css into that folder.
5. Before publishing, edit index.html and replace:
   - the href="#" on the WhatsApp booking button with your WhatsApp click-to-chat URL (https://wa.me/20YOURNUMBER)
   - the href="#" on the location link with your exact Google Maps URL.
6. Check the site on mobile and desktop.

NOTES:
- This is a static HTML/CSS landing page, ready to upload to standard web hosting.
- The hero uses a remote image from Unsplash and Google Fonts, so internet access is needed for those external assets.
- Service descriptions should be adjusted to reflect only services currently offered.
